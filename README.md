# VolumeState

VolumeState is a scalable, real-time data processing engine for auto-scaling clusters and a centralized manager for server monitoring.

VolumeState is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/VolumeState.git`
2. `cd VolumeState`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
